Эти два объекта создаёт `start-k8s.bat`: общие ключи и пароль NATS попадают в
`parkslot-shared`, а закрытый ключ подписи и пароль администратора — в
`parkslot-auth`, который читает только Auth. Шаблон рядом предназначен для
показа структуры на защите и не входит в `kustomization.yaml`.

Локальный файл `.local/k8s.env` создаётся при первом запуске, не включается
в образ, архив или Git и используется повторно. Посмотреть имена и число
ключей без значений: `kubectl --context parkslot-lab3 -n parkslot get secrets`.
