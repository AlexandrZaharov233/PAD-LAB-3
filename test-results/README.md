# Результаты проверок

После запуска `TEST_AND_PUSH.bat` отчёт с вашего ПК появляется в
[local/latest.md](local/latest.md), а исходные структурированные данные —
в `local/latest.json`. До первого запуска этих файлов нет.

Проверяются реальный API, оплата с промокодом, несколько Gateway и сохранность
брони после замены Pod Booking. Статус `PASS` записывается только после
успеха всех проверок. Неудачный или неполный запуск публикуется как `FAIL`.

Каждый push запускает независимые Python-тесты в [GitHub Actions](https://github.com/AlexandrZaharov233/PAD-LAB-3/actions).
JUnit и JSON по заданиям находятся в артефактах конкретного запуска Actions.
Отчёт с ПК и проверка GitHub показывают разные запуски и не подменяют друг друга.

Локальные учётные данные, токены, ключи и полные журналы в отчёт не включаются.
